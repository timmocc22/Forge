# HTML 创作工作台路线

## 已完成的第一版

- 产品主界面收敛为项目空间与 HTML 工作台。
- 可编辑分镜、单页与批量生成、页面顺序和锁定。
- 统一项目文档、手动源码编辑、当前页 AI 续改、撤销。
- 静态文字点选替换、当前页技术检查、隔离预览与放映。
- HTML 导入、离线演示 HTML 导出、项目 JSON 备份。
- 模型选择、运行状态、取消、失败保留成果、重启中断提示。

## 下一步：完善编辑闭环

- 版本历史浏览、显式草稿冲突对照、JSON 项目导入。
- 稳定场景 / 元素标识与结构化补丁，降低源码整体修改影响。
- 圈画与定位批注，多条修改合并提交。
- 逐页截图、全项目检查、带范围与次数限制的自动返修。
- 真实模型内容质量、响应时延与成本验收。

## 素材与复用

- 项目素材管理、资源离线化与统一引用。
- 图解、对比、时间线等可组合内容组件。
- 项目设计规范、可编辑变量与模板复用。

## 动效与视频

- 统一可定位到任意时间的动画协议，预览与导出使用同一时钟。
- 评估 HyperFrames SDK / Player 的适配；保留现有 iframe 隔离边界。
- 先验证短片的逐帧渲染、字体与资源一致性，再提供 MP4。
- 后续按需要加入时间轴、配音、字幕与音轨。

## 基础设施

当前保留模块化单体与单进程本地服务。文档、历史、任务分别按实际规模演进到数据库、增量历史和可靠队列。需要多人使用时再补齐认证、授权、共享与审计。
