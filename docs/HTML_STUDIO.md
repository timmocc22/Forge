# HTML 项目工作台

2026-11-03 起，产品主线收敛为 HTML 项目创作。旧版插件底座与非 HTML 创作模块已从代码中移除，历史数据不迁移或删除。

## 页面与工作流

主导航将“对话”和“作品”分为两个独立页面。新对话输入框位于页面底部，保留模型选择、HTML 导入和折叠的创作选项；不显示欢迎标题与创作建议按钮。

作品页在左侧列表直接展示作品标题、内容摘要与页数，选中后右侧直接展示画布、源码、分镜和属性，占满剩余空间，不再保留中间信息区。对话页展示当前创作要求、真实分镜和运行状态，底部输入页面问题或修改要求；右侧预览可以独立打开或关闭。

作品页拖动列表与内容之间的边界，预览随列表宽度自动扩缩；对话页可独立拖动预览宽度。支持键盘方向键微调、双击还原和扩张/收起；宽度偏好保存在本机浏览器。窄屏列表覆盖在内容之上，选中作品后自动收起。预览中的“页面”和“属性”面板按需打开，保持画布优先。

用户先编辑结构，再显式启动生成；切换项目、AI 续改与导出前保存当前文档。支持当前页文字点选替换、源码编辑、页面顺序调整、增删、锁定、撤销与离线 HTML 导出。

品牌标记统一使用折叠式 F 图形，覆盖侧栏、网页图标和桌面安装图标。生成时侧栏标记与状态条同步亮起，当前生成页面和状态条使用球形流体光晕；进度仅使用服务端返回的实际完成页数，分镜规划采用不定进度。完成后平滑呈现页面，取消或失败后结束动效并保留已有内容；系统开启“减少动态效果”时呈现静态状态。

生成按钮只生成未完成且未锁定的页面。当前页续改只把该页最新 HTML 传给模型，其他页面只提供标题与目标作为叙事上下文；服务端只提交目标页的生成结果。本地演示对话只返回规则说明，不执行自动修改。

页面助手支持连续对话，默认通过工具既能回答也能修改指定页面；开启「询问模式」时只读：每个项目保存一份 `Conversation { id, projectId, messages[] }`，消息记录 `id`、`role`、`content`、`sceneId` 和 `createdAt`。刷新或重新打开项目后恢复问答；切换页面保留前文，并用页面标识区分历史内容与当前页。只读询问只追加消息，不修改页面、项目 revision 或撤销历史。

每次成功回复将用户问题与助手回答作为一轮原子保存；失败时保留输入供重试，不把错误当作助手回答。调用文字模型时附带最近最多 10 轮完整问答，历史内容合计不超过 64000 字符，完整记录仍保存在本地，最多 1000 条。演示模式继续明确标注未调用 AI，不模拟语义追问能力。同项目同时只接受一轮对话。`GET /api/html-projects/:id/conversation` 读取记录，`POST /api/html-projects/:id/questions` 接收 `allowEdits`（默认 `true`），返回答案与更新后的记录；发生修改时同时返回 `project`，前端刷新列表与预览。旧项目首次询问时自动建立记录。

工具包括 `list_scenes({})`、`read_scene({ sceneId })` 和 `revise_scene({ sceneId, expectedRevision, instruction })`。后端严格校验参数、当前项目内的页面、锁定状态和版本。修改以请求内草稿执行，字段与 HTML 一起更新；最终答复通过校验后，再次检查目标页与全局创作属性，合并不冲突的页面草稿并原子保存页面和完整问答，撤销历史只增加一份修改前快照。失败、超时、关闭或版本冲突会放弃本轮草稿。只读模式不提供修改工具，执行端也拒绝修改。工具循环最多 12 次，逐一回传调用结果并保留推理项；并发限制按模型 HTTP 请求计数，执行工具时不占用模型额度，避免嵌套模型调用死锁。

消息协议校验完整的用户 / 助手顺序、唯一消息标识和每轮一致的页面关联；仓库校验对话所属项目。磁盘写入失败时不保留半轮记录，原项目内容保持原样，可重新发送。

## 数据与执行边界

- `packages/contracts/src/html-project.ts`：项目、页面、分镜结果和请求的 Zod 协议。
- `apps/api/src/projects/persistence/project.repository.ts`：本地 JSON 仓库、隔离快照与串行原子写入。
- `apps/api/src/projects/authoring/project.service.ts`：项目版本、撤销历史、分镜与页面生成。
- `apps/api/src/projects/conversation/conversation.service.ts`：连续对话、草稿提交、消息保存与任务清理。
- `apps/api/src/projects/conversation/scene-tools.ts`：页面工具定义、参数与状态检查、单页修改草稿。
- `apps/api/src/projects/conversation/conversation-context.ts`：无状态的模型上下文组装。
- `apps/api/src/projects/runtime/project-tasks.ts`：生成与询问共享的任务容量和关闭信号。
- `apps/web/src/views/html-studio`：创作工作台、编辑状态、沙箱通信与演示导出。
- `apps/web/src/services/html-projects.ts`：校验响应的 HTTP 客户端。

项目元数据与运行状态保存在 `DATA_DIR/html-projects/<uuid>.json` 版本化清单，内容、历史和草稿引用 `objects/` 下的可复用对象。同一进程内串行写入，先保存对象，再以临时文件 + rename 原子替换清单。仅在持久化成功后更新内存。每次修改增加 revision；客户端提交 expectedRevision，版本不一致返回 409。操作标识去重最近 100 次操作，历史保留最近 20 个完整内容快照。相同内容快照复用对象；当前内存仍保留记录，作品库扩大时可通过存储端口切换 SQLite 或增量历史。当前不是多进程仓库。

分镜与页面生成均先持久化运行记录，再调用服务适配器；每次运行保存模型快照。最多同时生成两个项目，实际模型并发仍受 ProviderRouter 限制。批量页面顺序执行，每个成功页立即保存，首次内容提交建立本次运行的撤销快照。用户取消后先将状态设为 cancelled，迟到结果不得提交。进程重启时运行中的任务改为 failed，保留成功页面，不自动重复付费请求。单次项目运行总上限为 10 分钟，模型适配器自身仍有单请求超时。

浏览器未保存内容写入以窗口会话隔离的 IndexedDB 草稿。恢复时保留 baseRevision，遇到冲突不会把旧草稿悄悄改成新基线。JSON 下载可备份当前草稿。服务端文档是手动编辑、AI 续改和 HTML 导出的统一数据来源。

## 预览与导出

生成 HTML 仍处于 `sandbox="allow-scripts"` 的不透明来源 iframe。预览插入 CSP，禁止联网与访问宿主。受控脚本把选中文字和当前页检查结果通过 postMessage 发给宿主；宿主同时校验 frame window、随机会话标识和消息形状。静态文字替换先在 DOMParser 中校验源元素及原文，不把模型 HTML 写入宿主 DOM。

导出文件包含全部页面，在独立沙箱 iframe 中显示，提供前后翻页。项目在未完成全部页面前禁止完整 HTML 导出。JSON 下载包含当前草稿，可在保存冲突时备份。当前没有 JSON 导入或视频输出。

## 验证

服务测试覆盖：分镜与构建分离、保存与重载、版本冲突、操作去重、人工修改作为续改上下文、非目标页不变、锁定跳过、批量生成去重、撤销、取消迟到结果与重启恢复。浏览器测试覆盖主题到导出的完整流程、源码刷新恢复、逐页修改、点选文字替换、当前页检查，以及移动端导入与画布隔离。

生成动效来源：[andrew-manzyk / young-walrus-64](https://uiverse.io/andrew-manzyk/young-walrus-64)，按 MIT 许可使用，完整许可随前端静态资源发布。组件为每个实例生成独立 SVG 标识，并将填充和遮罩置于同一个 SVG 中，以兼容 WebKit 与缩放显示。

## 执行基础升级

消息追加与中断由服务端持久化命令队列处理。关闭浏览器后已接收任务继续执行；服务重启后等待手动重试。多步修改记录步骤与隔离草稿，相同请求和基线下继续未完成步骤；不会将未完成草稿显示成已保存作品。存储格式、兼容规则与 RAG / 多作者扩展边界见 [架构说明](ARCHITECTURE.md#可迭代的执行基础2026-11-05)。
