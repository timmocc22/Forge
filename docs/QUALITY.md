# 质量验证

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm format:check
```

- 协议与单元测试覆盖 HTML 输入、项目持久化、版本冲突、撤销、锁定、取消和定向续改。
- 模拟 HTTP 测试覆盖文本模型路由、独立密钥与代理、结构化输出、HTML 完整性和脱敏错误。
- HTTP 集成测试覆盖项目读写、模型目录以及退役接口不可用。
- 浏览器验收覆盖创作、导入、源码保存、点选、导出、对话历史、可调侧栏、手机布局，以及生成动效的完成、取消、失败和减少动态效果设置。

自动化默认使用本地演示或模拟模型响应，不调用付费模型。它们验证应用链路，不证明外部账户额度、权限或实际模型的生成质量。桌面原生保存与安装包验收单独记录。
