## 多语言浏览器修复

实际浏览器携带超过十项语言偏好的 `Accept-Language` 请求头时，Tomcat 在进入控制器前抛出异常，导致项目列表、模型目录和存储状态返回 500。已通过连接器配置取消语言数量上限，继续保留 HTTP 请求头大小限制；Spring Boot 当前依赖版本没有对应的自动配置属性，因此采用独立连接器定制配置。

新增真实 HTTP 回归测试（普通语言列表与 13 项语言列表），后台 18 项测试通过。重启后，实际浏览器携带 13 项语言偏好访问上述接口均返回 200，页面没有项目错误或模型连接占位提示。前端、API、Python 服务分别在 5179、3009、3017 正常运行。
