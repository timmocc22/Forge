# 界面设计

工作台保持简洁的明暗主题，主导航提供对话和作品两个页面。折叠式 F 标记统一用于侧栏、网页与桌面图标资源。

对话历史在左侧独立侧栏。对话内容展示创作要求、真实分镜和生成状态，输入框固定在内容底部。模型选择、HTML 导入和创作选项集中在输入框周围。

作品列表显示名称、摘要和生成页数，选中后右侧直接展示内容。预览区支持画布、分镜总览和 HTML 源码；页面列表与属性按需打开。列表、预览与属性宽度可调整，窄屏侧栏使用覆盖布局。

生成时使用 andrew-manzyk 的球形流体光晕，预览区与状态条使用同款动效；进度来自服务端完成页数，取消、失败或完成后停止持续动画。减少动态效果设置下使用静态状态。

具体交互和数据约束见 [HTML_STUDIO.md](HTML_STUDIO.md)。

生成动效来源：[andrew-manzyk / young-walrus-64](https://uiverse.io/andrew-manzyk/young-walrus-64)，按 MIT 许可使用，完整许可随前端静态资源发布。组件为每个实例生成独立 SVG 标识，并将填充和遮罩置于同一个 SVG 中，以兼容 WebKit 与缩放显示。
